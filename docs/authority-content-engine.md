# Authority and case-study content engine

This is the operating brief for the Content Authority epic (#28).

## First production outcome

Create a small, source-backed library that helps students, employers, and
schools make better placement decisions, while making DIVD.Works' own
experience discoverable without turning generic SEO copy into published fact.

## Initial release scope

- Three student pathway guides.
- Four employer practice guides.
- Three school practice guides.
- A first-party resource index with explicit audience and next action.
- A methodology note before any platform-data article is published.

## Quality gates

- Every guide has a named audience, source links, and one conversion path.
- Guidance is labelled as guidance; observations and outcomes are sourced.
- No resource is generated from a keyword list alone.
- A resource is not published if its source, reviewer, or owner is missing.
- The static build and internal-link checks pass before release.

## Ownership

The code and editorial structure are implemented here. A human DIVD.Works
editorial owner still needs to be assigned before these pages should be
treated as an ongoing publication programme. That missing assignment is an
owner decision, not something the repository can safely invent.
